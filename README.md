# assembly-julia-set
A Julia Set visualization program implemented using ARM Assembly and C as the final project for the Assembly Language and Embedded Systems (IC) course.

Completed: January 2024
Project Type: Course Final Project (Team of 3)

Overview
This project implements a Julia Set visualization using low-level ARM Assembly programming together with C. The program performs iterative Julia Set calculations, determines pixel colors based on the computation results, and stores the generated values in a frame buffer for visualization.
